# Email Deliverability Standards

> Apply these rules to every email subject line and body before sending. A great email that lands in spam is a wasted email.

---

## Subject Line Rules

### Words and phrases that increase spam score — avoid entirely

| Word / Pattern | Notes |
|----------------|-------|
| ALL CAPS words | Any word in full caps adds to spam score |
| Multiple exclamation marks !! | One is borderline, more than one is a flag |
| Free | Classic spam trigger |
| Stop | |
| Lose | |
| Now | Common and frequently flagged — replace with specificity |
| Open | |
| Power | |
| Start | |
| Call | |
| Here | |
| Savings | |
| Credit | |
| Discount | |
| Join | |
| Ends | |
| Get | |
| Today | |
| Success | |

**Example of what not to do:** *"She helped me uncover $200K - now it's your turn"* — "now" is flagged.
**Fix:** Replace "now" with something specific — *"She helped me uncover $200K — you're next"* or reframe entirely.

### Subject line principles
- Specific beats vague
- Curiosity beats announcement
- One idea only — not a summary of the email
- Test before sending (see tools below)

---

## Body Copy Rules

- No ALL CAPS words anywhere in the body
- Avoid the trigger words listed above in body copy too — especially in opening lines and CTAs
- Don't use multiple exclamation marks in a row
- Avoid "$$$" or excessive currency symbols
- One CTA — not three variations of "click here / sign up / get access now"

---

## Before Every Send — Two Checks

**1. Subject line tester:** [sendcheckit.com/email-subject-line-tester](https://sendcheckit.com/email-subject-line-tester)
Grade your subject line before sending. Aim for a strong score — flag anything yellow or red.

**2. Full email spam score:** [spamcheck.postmarkapp.com](https://spamcheck.postmarkapp.com)
Paste the full email HTML or text. Score of 0 is perfect. Flag anything above 1.

Run both checks as the final step before scheduling or sending.
